# CodeForensic

> Investigate. Trace. Explain.

## Core Philosophy

> Every change leaves evidence.

CodeForensic is a software investigation platform that analyzes real software projects to uncover code changes, Git history, dependencies, security findings, risk signals, and potential impact.

## Development Philosophy

CodeForensic is designed to work with real project evidence.

The application must not fabricate:

- Project statistics
- Git history
- Contributors
- Dependencies
- Security findings
- Risk scores
- Investigation evidence

If sufficient evidence is unavailable, the system should explicitly report that limitation.

## Security

Imported projects are treated as untrusted input.

Uploaded code must never be executed automatically.

Secrets and API keys must remain outside source control.

See [SECURITY.md](docs/SECURITY.md) for the security approach.
